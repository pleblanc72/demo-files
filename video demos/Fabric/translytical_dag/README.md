# Translytical-DAG
This repository provides a complete, end-to-end solution for deploying a Directed Acyclic Graph (DAG) using Microsoft Fabric workloads. 

#### Before deploying this solution ensure your workspace is backed by one of the following Fabric/Power BI licenses:

- Fabric Capacity
- Premium Capacity
- Fabric Trial Capacity

#### The following Tenant Settings should be enabled:
- SQL Database Enabled on Capacity
- User Data Functions Enabled on Capacity

#### The following Power BI Desktop Preview Features should be enabled:
- Translytical task flow
- Button slicer visual
- List slicer visual
- Text slicer visual
